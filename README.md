## Technical Specifications

The **FALCON-II** is a high-speed, scratch-designed experimental scale Supersonic RC aircraft. It is engineered around Kingtech's Kg320 g5 Turbojet engine and a multi-axis control surface layout to study level Supersonic airflow behaviors, material behaviour and intake fluid dynamics.

* **Total Length of Aircraft:** 2.4m+
* **Total Height of Aircraft (no landing Gear):** 0.2m (~24cm)
* **Fuselage Hull Height:** 0.15m (~15cm) 
* **Wingspan:** >~1.1m
* **Wing Area:** ~Not known
* **Total Control Channels:** 4 Channels (2x Elevons, 2x Rudders)
* **Performance Profile:** Estimated empty airframe weight ranges from 20 - 24 kg. Powered by a Kingtech's K320 g5 Turbojet engine producing between 28 - 32 kgs of static thrust, yielding a > 1:1.3 (4:3) thrust-to-weight ratio for a flight envelope targeting MACH 1.3 - MACH 1.65.
